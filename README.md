## About

I'm Hallelujah, an **independent developer & consultant** based in Addis Ababa, Ethiopia. I work **both ways** — full-stack development in **.NET, TypeScript, and Flutter** when an engagement needs custom code, and the **Microsoft Power Platform** when low-code is the faster, fitter answer.

- BSc Software Engineering — Addis Ababa Science & Technology University
- Engagements include a production internal app for **Ethiopian Airlines**, ongoing consulting for **Eaglepoint AI**, enterprise Power Platform delivery with **Vision Vertex**, and independent client work across both disciplines.
- Currently taking on contracts — discovery, build, ship — for teams that want real, working software instead of slide decks pretending to be products.
